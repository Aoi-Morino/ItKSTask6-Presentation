# 知識科学概論 第六回レポート課題

画面切り替え時に、録音した音声がどうなっているか録音時分からなかったため、変な間があります。ご了承ください。

## pptxファイルについて

プレゼンテーションに使用したスライドです。

ナレーションは録音しているため、スライド ショーの"最初から", "現在のスライドから"で、そのまま視聴することができます。

課題の指示がpptxファイルでの提出だったため一緒にアップしていますが、下記のリンクから、YouTubeで見たほうがいいと思います。

## プレゼンテーション台本について

プレゼンテーションで読んだ台本です。

自分が読みやすいように書いてるだけです。

`[!]`は、スライドを進めるタイミングの目安です。
